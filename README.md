# AI Coding Skills

Personal collection of reusable AI skills for software development, code audits, architecture refactoring, and token-efficient workflows. Clone this repository into any new environment to get your exact AI setup immediately.

## Why This Exists
Spinning up a new machine, container, or repository should not mean rebuilding your AI instructions from scratch. This repository centralizes your active coding skills so every new environment starts with the same standards and response style.

## Usage
Clone the repository into your skills directory:

\`\`\`bash
git clone https://github.com/devanshrautela/skills/
\`\`\`

## Skills Included
- **ponytail:** Minimal-change ("lazy senior dev") coding mode focused on small, targeted diffs and concise summaries.
- **thermo-nuclear-code-quality-review:** Strict maintainability audit targeting giant files, weak abstractions, and sprawling conditional logic.
- **caveman:** Terse, high-signal output mode that strips filler while keeping technical accuracy intact.
- **improve-codebase-architecture:** Workflow for spotting architectural deepening opportunities, generating a visual HTML report, and reviewing candidate changes.
